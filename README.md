# Espresso Lab

WebXR barista trainer for Meta Quest (and desktop preview). Learn to make an espresso step by step: grind, tamp, lock, brew, serve.

- **Grab with the side grip button** (or the trigger when pointing at an object). Hold it and place it yourself. Press buttons with the trigger.
- **Guided mode:** hints, labels, green rings that show where things go, and new English words.
- **Test mode:** no help, mistakes are counted.

Open the page in the Meta Quest Browser and tap **Enter VR** (or **Mixed reality**).

Built for Speak Academy.
